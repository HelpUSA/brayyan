# Brayyan

Sistema web para auditoria e visualizacao de revisoes sistematicas com triagem 100% automatizada por IA.

## Conceito

O Brayyan substitui o trabalho humano de triagem de artigos por IA, mantendo o mesmo fluxo de trabalho do Rayyan. O pesquisador faz upload dos CSVs processados pelas IAs (ChatGPT, DeepSeek, Claude) e o sistema oferece:

- Visualizacao das decisoes com scores de confianca
- Consenso automatico entre dois watchers
- Deteccao e resolucao de conflitos
- Metricas de concordancia (Cohens Kappa)
- PRISMA Flow Diagram automatico
- Exportacao para publicacao

## Tech Stack

- Frontend: React + TypeScript + Vite + TailwindCSS + shadcn/ui
- Backend: Python + FastAPI + SQLAlchemy + Pandas
- Database: PostgreSQL
- Deploy: Vercel (frontend) + Railway (backend)
